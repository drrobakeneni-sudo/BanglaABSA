# Preprocessing

The code is a reconstruction because the manuscript's original dictionary, dependency parser, cue resources, and alignment details are unavailable.

1. NFC Unicode and whitespace normalization preserve Bangla marks, negation, emoji, and meaningful zero-width joins. The optional 5–256 filter counts whitespace-delimited words, an explicit reconstruction choice. The separate model length is at most 256 tokenized positions **including special tokens**. The conservative script filter recognizes Bangla or Latin characters; it is not a trained language identifier.
2. Demonstration dictionary transliteration handles a small authored vocabulary. Optional ordered phoneme substitutions run only on an explicitly allowed candidate-word list. Unrecognized Latin words are retained and counted, preserving English words instead of assuming every Latin token is Banglish. No complete transliteration coverage is claimed.
3. Rule-based sentence/clause segmentation uses punctuation and contrast markers. Authored aspect-cue lists align clauses to categories without labels. Unaligned clauses remain global context. There is no hidden dependency-parser substitution: the manuscript parser is missing, and this release uses **rules only**. RAM/LCF use text-derived clause alignment; ordinary M4/M5 learn attention over the entire sequence.
4. The cue lexicon is fitted only on TRAIN using token/polarity co-occurrences from observed aspect labels. This heuristic assigns a token the most frequent polarity only when uniquely determined and sufficiently observed. It can be noisy in multi-aspect text; it is a reconstruction, not proof of the paper's lexicon. No star ratings are read. Subwords inherit the cue of their containing complete token using tokenizer offsets. Padding, special tokens, and unknown cues have ID zero; IDs 1–3 represent Negative/Neutral/Positive and index learned embeddings.
5. Training saves the lexicon, mappings, transform version/checksum, tokenizer files, checkpoint revision, and model configuration. Evaluation loads them and never refits. The tiny/static vocabulary learns ordinary tokens on TRAIN; fixed category phrases are known task definitions, not held-out data.

Grouping occurs on normalized/transliterated text before splitting and is checked again at training. `--deduplicate` can consolidate exact duplicate text if labels agree, but the default retains records while keeping duplicates and linked group IDs in one partition. Conflicting duplicate labels require adjudication. Private preparation metadata includes file hashes, counts, exclusions, and split provenance. It does not print raw reviews. Hashes are reproducibility aids, not anonymization, and stay in ignored local directories.

For custom permitted resources, construct `Transliterator(mapping=..., rules=..., candidates=...)` and `Pipeline(transliterator=...)`, then save/reuse the resulting state. Updating preprocessing changes the run signature and invalidates caches/checkpoints.
